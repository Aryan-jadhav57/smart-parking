
# Smart Parking Solution using Blockchain

A secure, transparent, and efficient smart parking system built with **Blockchain** and **Web3 technologies**.  
This project enables drivers to locate available parking spaces in real time, reserve slots, and make seamless digital payments through decentralized smart contracts.

---

## 🚀 Features
- **Real-Time Slot Detection**: Prevents double-booking and ensures accurate availability.
- **Blockchain-Powered Payments**: Tamper-proof transaction records using Solidity smart contracts.
- **Decentralized Platform**: Eliminates reliance on centralized servers, enhancing trust and transparency.
- **Scalable Backend**: Flask + MongoDB for efficient data management and smooth user experience.
- **Secure Authentication**: JWT-based login and encrypted transaction logs.

---

## 🛠️ Tech Stack
- **Backend**: Python (Flask), MongoDB  
- **Blockchain**: Solidity, Web3, JSON Chain  
- **Frontend**: HTML5, CSS3, JavaScript (optional integration)  
- **Other Tools**: RESTful APIs, JWT Authentication

## ⚙️ How It Works
1. **Driver opens app** → Views available slots.  
2. **Selects slot** → Reservation request sent to backend.  
3. **Smart contract executes** → Payment processed securely on blockchain.  
4. **Slot confirmed** → Transaction logged immutably.
